Fabrication and Media Design

Making in the Physical and Digital World

  • Fall 2026
  • UCR Library Honors Ignition Seminar
  • 4 units
  • Co-taught with Jing Han

This was the first credit-bearing course taught by Research Services at the UCR Library. The seminar introduces students to hands-on making across physical and digital domains. The first half covers physical fabrication (vector design, laser cutting, electronics, 3D printing, and video production) in the Creat'R Lab, the makerspace at UCR's Orbach Science Library. The second half moves to interactive fiction, creative coding, machine learning, and critical AI practice. Students documented their work throughout and built a public portfolio on GitHub.

I led Weeks 1–4, the physical fabrication half of the course.

Learning outcomes
  1. Operate physical fabrication tools including laser cutters, Cricut machines, and 3D printers to produce original objects
  2. Wire and program basic electronic circuits using Arduino and simulate them in Tinkercad
  3. Produce a short video project using non-linear editing software and basic compositing techniques
  4. Build an interactive text-based narrative using Twine or generative grammar using Tracery
  5. Create a browser-based generative or interactive sketch/game using p5.js or Bitsy
  6. Train and apply a machine learning model using Teachable Machine and ml5.js
  7. Run and critically evaluate a locally hosted AI model, comparing it to cloud-based alternatives
  8. Maintain a public GitHub portfolio documenting process and reflection across all eight projects
